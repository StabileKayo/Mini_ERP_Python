# Mini ERP Python

Mini ERP desenvolvido em Python com integração ao MySQL para fins de estudo e prática de desenvolvimento back-end.

## Objetivo

Este projeto tem como objetivo desenvolver um sistema ERP simples, aplicando conceitos de:

- Python
- MySQL
- CRUD (Create, Read, Update e Delete)
- Organização de código
- Git e GitHub

O projeto será expandido gradualmente com novas funcionalidades, simulando o desenvolvimento de um sistema real.
